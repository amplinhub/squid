# GROW UP

Подводная 3D-игра в браузере: начни мальком кальмара и вырасти в кракена.
Перенос с Game Maker 8 на JavaScript и [three.js](https://threejs.org).

- Играть: https://amplinhub.github.io/squid/ (появится после первого релиза)
- План переноса: [docs/PLAN.md](docs/PLAN.md)

# GROW UP (English)

An underwater 3D browser game: start as a tiny squid and grow into a kraken.
Ported from Game Maker 8 to JavaScript and three.js.
